# Mobile Factory Space Age

This is a unified Factorio 2 edition of Mobile Factory. The former Mobile Factory,
MF Base, and Mobile Factory Graphics packages are bundled into this single mod.

- Display name: Mobile Factory Space Age
- Maintainer and package author: BEHROOZZX
- Factorio compatibility: 2.0
- Space Age: optional
- Space Age cargo weight: one Mobile Factory per standard rocket
- Save compatibility: intended for new games; legacy save migration is not included

The original Mobile Factory and MF Base work was created by Mugiwaxar. Factorio 2
porting work from the public killzoms fork was used as a technical reference. This
unified edition is maintained and packaged by BEHROOZZX.

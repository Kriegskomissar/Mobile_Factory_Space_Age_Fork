Version: 1.0.0
Date: 2026-10-29
  Major Features:
    - Reworked the mod into a standalone Factorio 2.1 + Space Age mobile-factory project.
    - Added tiered Small, Super and Mega Mobile Factories with separate interior factory spaces.
    - Added the on-board production concept with interior inventory access and factory terminals.
    - Added the Jump Drive Mk.I, Mk.II and Mk.III progression and the independent Jump Charger technology.
    - Reworked the factory technology progression around Tank, Small Factory, Chemical Science and Metallurgic Science.
  Compatibility:
    - Targets Factorio 2.1 with Space Age as a required dependency.
  Changes:
    - Renamed the mod ID to Mobile_Factories_Onboard_Production so this project is a separate mod rather than an update of Mobile_Factory_Space_Age.
    - Set the display title to Mobile factories: On-board production.
    - Removed the obsolete multi-factory interior runtime override and its former exterior-energy transfer logic.
    - This release is intended for a fresh game and is not a save-compatible update of the previous Mobile Factory Space Age package.

Version: 1.0.6
Date: 2026-10-25
  Compatibility:
    - Updated to Factorio 2.1, tested with Headless 2.1.23 in Base and Space Age.
    - Migrated fluid access, fluid extraction and cross-surface pump connections to the 2.1 API.
    - Updated fuel categories, recipe categories and assembler pipe graphics to the 2.1 API.
    - Updated product probabilities, including shared probability ranges and variable output counts.
  Bugfixes:
    - Fixed item duplication when distributing items over multiple Deep Storages or transferring from an empty inventory.
    - Matter Interactors, Network Explorer imports and logistic lasers preserve stacks that the name/count data network cannot represent (quality, blueprints, damage, durability, partial ammunition and spoilage).
    - Data Assembler retains rolled products while output is blocked, including across save/load, and removes only accepted output from the pending craft.
    - Fixed Resource Collector automatic fluid selection and preserved transferred fluid temperature.
    - Avoided invalid zero-volume Deep Tank temperature calculations and missing cosmetic mining projectiles for manually supplied fluids/items.
    - Restricted adjacent scripted energy sharing to the same force.
    - Protected-call errors are now recorded in the server log as well as displayed to players.
  Notes:
    - Existing capacities, recipe costs, rates, startup defaults and optional Space Age support are preserved.
    - No external graphics mod is required; the bundled graphics are unchanged.
